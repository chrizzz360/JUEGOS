¿Qué son DAS y ARR?

DAS (Delayed Auto-Shift): cuántos frames debes mantener ← o → antes de que la pieza empiece a deslizarse sola. Menos = reacciona más rápido; más = menos deslizamientos accidentales.

ARR (Auto Repeat Rate): una vez pasado el DAS, cada cuántos frames avanza una casilla. Con 0 salta de golpe hasta la pared.

1 frame = 1/60 s.
